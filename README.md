# Around the U.S. com Express
![Express.js](https://img.shields.io/badge/express.js-%23404d59.svg?style=for-the-badge&logo=express&logoColor=%2361DAFB) ![MongoDB](https://img.shields.io/badge/MongoDB-%234ea94b.svg?style=for-the-badge&logo=mongodb&logoColor=white)

## Descrição
É a API que será usada no projeto Around the U.S.. Ela gerencia os dados dos usuários e das postagens criadas por eles, fazendo a intermediação entre o lado do cliente e o banco de dados.

## Tecnologias 
Foram utilizados o framework Express.js na criação da API e a ferramenta Mongoose para facilitar a interação com o banco de dados MongoDB.
